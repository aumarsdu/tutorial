# 网站开发说明

本文档给出一个**可落地的网站开发方案**，适合从 0 到 1 搭建企业官网、产品官网或内容站。

## 1. 明确目标与范围

先把下面 5 件事写清楚：

1. **业务目标**：例如获取线索、展示品牌、在线下单、用户注册。
2. **核心用户**：他们是谁、主要痛点是什么、会通过什么设备访问。
3. **核心页面**：首页、产品页、关于页、博客页、联系页等。
4. **关键转化动作（CTA）**：咨询、预约、购买、下载、注册。
5. **上线时间与预算**：决定你是做 MVP（最小可用版本）还是完整版本。

> 产出建议：1 页 PRD（产品需求文档）+ 页面清单。

## 2. 技术栈建议（推荐）

### 前端
- **Next.js（React）+ TypeScript**：利于 SEO、性能和工程化。
- **Tailwind CSS**：快速构建一致的 UI。
- **组件库（可选）**：如 shadcn/ui，提升开发效率。

### 后端
- 如果是内容型网站：
  - 可先用 Next.js API Routes / Server Actions。
- 如果有复杂业务：
  - 使用独立后端（Node.js/NestJS 或 Python/FastAPI）。

### 数据库与存储
- **PostgreSQL** 作为主库。
- **Prisma** 作为 ORM（Node 场景）。
- 图片与文件放到对象存储（S3 兼容服务）。

### 运维部署
- 优先选择 **Vercel**（前端）+ 托管数据库（如 Supabase/Neon）。
- 开启 HTTPS、CDN、日志监控与告警。

## 3. 项目结构建议

```text
web/
  app/               # 路由与页面
  components/        # 可复用组件
  lib/               # 工具函数、配置、SDK
  styles/            # 全局样式
  public/            # 静态资源
  tests/             # 测试
  docs/              # 需求和设计文档
```

## 4. 开发流程（建议按周推进）

### 第 1 周：需求与原型
- 梳理用户路径（从进入网站到完成转化）。
- 用 Figma 产出低保真原型。
- 冻结 MVP 范围，避免边做边改。

### 第 2 周：基础工程搭建
- 初始化 Next.js + TypeScript + ESLint + Prettier。
- 建立组件规范（按钮、表单、卡片、导航）。
- 配置环境变量（`.env`），区分 dev/staging/prod。

### 第 3 周：核心页面开发
- 完成首页、关键落地页、联系表单。
- 接入埋点（如 GA4/自建埋点）。
- 优化 SEO：title、description、OG、结构化数据。

### 第 4 周：联调、测试、上线
- 功能测试 + 响应式测试 + 性能优化。
- 配置 CI/CD（push 即自动构建与部署）。
- 上线后做灰度观察与数据复盘。

## 5. 必做的工程规范

1. **Git 流程**：`main` 稳定，功能分支开发，PR 合并。
2. **代码检查**：ESLint + TypeScript 严格模式。
3. **提交规范**：Conventional Commits（如 `feat:`、`fix:`）。
4. **测试**：
   - 单元测试：Vitest/Jest
   - E2E：Playwright
5. **质量门禁**：PR 必须通过 lint/test/build。

## 6. 上线前检查清单

- [ ] 所有页面移动端可用
- [ ] 首屏性能达标（LCP、CLS、INP）
- [ ] SEO 基础项完整（sitemap、robots、meta）
- [ ] 表单有防刷机制（验证码/限流）
- [ ] 404 / 500 页面可用
- [ ] 埋点可回收关键转化数据
- [ ] 隐私政策与 Cookie 提示合规（如适用）

## 7. 常见风险与规避

- **需求频繁变更**：用 MVP 和需求冻结点控制。
- **页面做得快但不可维护**：提前统一组件与设计 token。
- **只关注视觉忽略转化**：每个页面都要有明确 CTA。
- **上线后无数据闭环**：先埋点再上线，而不是上线后补。

## 8. 你们现在可以立刻执行的最小计划（7 天）

- Day 1：确认目标用户、核心 CTA、页面列表。
- Day 2：输出首页和落地页线框图。
- Day 3：初始化项目与 CI。
- Day 4-5：完成首页 + 联系表单 + 基础 SEO。
- Day 6：测试与修复。
- Day 7：上线并看首日数据。
